# 코퍼스 어휘 사전 기반 자동분류 개선 설계

- 날짜: 2026-09-12
- 상태: 승인됨
- 대상: `backend/book_classifier.py` 자동 분류 판정 로직

## 1. 문제

현재 `evaluate_category_decision()`은 우선순위 캐스케이드다.
먼저 맞은 신호가 곧바로 반환되고, 나머지 신호는 버려진다.

본문 기반 어휘는 `WUXIA/FANTASY/ROFAN/BL/ADULT_KWS` 5개 수작업 상수뿐이다.
`/mnt/data/text`의 카테고리 디렉토리(`번호_카테고리명`)는 88개이고, 그중 5개만 어휘로 덮여 있다.

따라서 두 가지를 만든다.

1. 코퍼스에서 뽑은 카테고리별 어휘 사전 (출현빈도 top 1000 + 고유 단어 세트)
2. 기존 신호와 신규 어휘 점수를 합산하는 가중치 합 판정

## 2. 측정된 사실

| kiwi 토큰화 | 1워커 57,754자/s → 8워커 199,676자/s | 동일 입력 반복 측정 |

## 4. 단어 추출

kiwi 토큰 중 `NNG`, `NNP`, `SL`, `SH`, `SN`만 남긴다.
원문에서 **문자 위치가 붙어 있는** 명사 토큰은 하나로 병합한다.

병합하지 않으면 도메인 용어가 부서진다.

```
입력: 그는 무림맹의 장문인으로서 내공을 운기조식하며 화산파 검법을 익혔다.
병합 전: 무림맹 / 장 / 문인 / 내공 / 운기 / 조 / 식 / 화산 / 파 / 검법
병합 후: 무림맹 / 장문인 / 내공 / 운기조식 / 화산파 / 검법
```

본문 추출은 `backend/category_lexicon.py`가 전담한다.
모델을 만들 때와 점수를 매길 때가 같은 함수로 같은 분량(head 20,000자 + tail 10,000자)을
읽어야 한다. 분류기 쪽 추출기는 `.txt`를 250줄까지만 읽어 학습 분량의 3분의 1도 주지
못했고, 그만큼 정확도가 떨어졌다(36.2% → 42.9%).

인코딩이 손상된 문서는 `utils/detect_mojibake.py`가 걸러낸다.
문서 6건짜리 카테고리는 손상 2건만으로 어휘 전체가 깨진 토큰이 된다.

## 5. 자질 선택 — 카이제곱

어휘는 **카이제곱 상위 30,000개**를 쓴다. 카테고리별 목록이 아니라 하나의 공통 어휘다.

```
χ²(w) = max over c of  N(N11·N00 - N10·N01)² / ((N11+N01)(N11+N10)(N10+N00)(N01+N00))
```

"이 단어가 나오는지 여부가 카테고리와 통계적으로 얼마나 연관되는가"를 잰다.

TF-IDF 순위로 고르면 안 된다. TF-IDF는 검색에서 중요한 단어를 고르는 척도지
분류에 도움되는 단어를 고르는 척도가 아니다.

| 고르는 기준 | 어휘 수 | 답한 20% 구간 정답률 |
|---|---|---|
| 문서빈도 | 60,000 | 77.9% |
| 카이제곱 | 60,000 | 89.0% |
| **카이제곱** | **30,000** | **90.2%** |
| 전체 | 262,994 | 85.0% |

같은 6만 개라도 고르는 기준이 다르면 77.9% 대 89.0%다.
그리고 잘 고른 3만 개가 전체 26만 개보다 낫다. 저장도 9분의 1이다.

## 6. 점수 계산 — Complement Naive Bayes

코사인 유사도(TF-IDF 중심점)에서 옮겨왔다. 그 방식은 원래 분류용이 아니라 검색
랭킹용이고, **맞은 단어 전체의 겹침 비율**을 보기 때문에 결정적 단어 하나가 흔한
단어 수백 개에 묻힌다.

```
40대 중년남의 하렘라이프
  9_어린이육아  87점   학부모, 초등학생, 아빠, 교실, 엄마   <- 학교 배경이라 등장
  9_성인       86점   발기, 애무, 자위, 섹스, 알몸        <- 실제 장르 증거
```

NB는 단어마다 로그 확률비를 **더한다**. 한 장르에만 나오는 단어는 큰 값을 더하고
어디나 나오는 단어는 0에 가까운 값을 더한다. 결정적 단어 하나가 판정을 뒤집을 수 있다.

Complement 변형을 쓰는 이유는 클래스 불균형이다.
3_판타지 78,027건과 9_격언명언 7건을 같은 저울에 올리는 문제를 이 변형이 정면으로 다룬다.

```
θ_c̄(w) = (여집합에서 w 의 출현 수 + α) / (여집합 전체 출현 수 + α·V)
weight_c(w) = -log θ_c̄(w) / Σ_w |log θ_c̄(w)|
score(c) = Σ_{w ∈ 문서 ∩ 어휘} weight_c(w)
```

모델은 가중치가 아니라 **원시 문서빈도**로 저장한다. 가중치는 어휘 전체에 조밀해서
그대로 저장하면 파일이 몇 배가 된다. 적재할 때 계산하며 1.2초 걸린다.

### 고유어 세트를 쓰지 않는 이유

원래 설계에는 카테고리별 고유 단어 세트가 있었고 1.5배 가산점을 줬다.
기준을 세 번 고쳐 판타지 17개·여성향 24개까지 뽑았고 측정상 기여도 있었다(+3.8%p).

그런데 NB는 **같은 정보를 단어별 로그 확률비로 이미 담는다.**
`검무`(무협 31%, 다른 곳 0.4%)와 `경장`(6% 대 4.9%)이 자동으로 다른 크기를 갖는다.
고유어 목록은 "존재 여부"만 관리해 이 둘을 구분하지 못했다. 그래서 걷어냈다.

## 7. 하위 카테고리 통합

출판사 전집·작가 전집은 장르가 아니라 묶음 이름이다.
`2_을유세계문학전집`과 `2_소설외국`은 같은 종류의 책이라 본문 어휘로는 구분되지 않는다.
따로 두면 같은 어휘로 서로 경쟁하며 점수를 깎고, 어느 쪽도 이기지 못해 판정이 보류된다.

15개를 상위 장르로 합친다(81개 → 66개). 하위 배정은 **파일명에 그 시리즈 이름이
정확히 들어 있을 때만** 한다.

```
[을유세계문학전집] 위대한 개츠비  →  2_을유세계문학전집   [series_in_filename]
위대한 개츠비                  →  본문 어휘로 2_소설외국 판정
```

## 8. 가중치 합 판정

### 순서는 관행이 아니라 실측 정답률로 정한다

| 판정 경로 | 실측 정답률 |
|---|---|
| 어휘 사전 (CNB) | 79.4% |
| 파일명 명시 장르 | 58.3% |
| EPUB 메타데이터·해시태그 | 55.9% |
| 기존 5대 장르 | 15.5% |

캐스케이드 시절의 관행적 순서(메타데이터가 위)를 그대로 쓰면 좋은 신호가
나쁜 신호에 끌려 내려간다. 어휘 사전을 메타데이터 위로 올리면
**답하는 양은 그대로인데 정답률만 70.9% → 76.6%로 오른다.**

### 사다리

| 기여 신호 | 가중치 | 단독 판정 |
|---|---|---|
| 파일명 시리즈 키워드 | 11.8 | 가능 |
| 제목 유사도로 검증된 단일 서점 매칭 | 9.4 | 가능 |
| 단일 서점 매칭 신뢰 | 7.5 | 가능 |
| **어휘 사전 (CNB)** | **5.4 ~ 6.0** | 가능 |
| EPUB `dc:subject` · TXT 헤더 · 충돌해소 | 4.3 | 가능 |
| EPUB `dc:description` · 해시태그 | 3.2 | 가능 |
| 기존 5대 장르 스코어링 | 1.2 ~ 1.5 | **불가 (보조만)** |
| 서점 매핑 1건당 | 1.0 | **불가 (보조만)** |

인접 신호는 전 구간 1.25배 이상 벌어져 있다. 정면 충돌 시 상위 신호가 마진을 넘어 이긴다.

기존 5대 장르는 66개 중 5개만 아는 분류기다. 그 5개 밖의 파일에 발동하면 반드시
틀리므로 단독 판정권을 주지 않는다. 실측에서 단독권을 줬을 때 가중치 합 정답률이
57.0%, 보조로 내렸을 때 73.4%였다.

### 채택 조건

```
최고점 >= 2.0
최고점 >= 2위 점수 × 1.25
```

어휘 사전 자체도 1위가 2위를 `MIN_MARGIN`(1.0068)배만큼 앞서지 못하면 답하지 않는다.
파일을 실제로 옮기는 용도라 정밀도를 앞에 둔다. 애매하면 손대지 않는다.

### method 문자열 보존

우승 카테고리를 지지한 기여자 중 캐스케이드 순서상 가장 앞선 것의 이름을 쓴다.
카테고리 **선택**만 가중치 합이 담당하므로 호출부 계약이 유지된다.

## 9. 검증 결과

파일이 이미 카테고리 디렉토리 안에 있으므로 정답 레이블이 이미 존재한다.
카테고리당 샘플의 20%를 학습에서 제외하고, 서점 조회를 끈 채 파일 내용만으로 판정했다.

홀드아웃 2,044건, 81개 카테고리 (무작위 추측 기준선 1.2%).

| 방식 | top-1 | top-3 | 무판정 |
|---|---|---|---|
| 기존 5대 장르 스코어링 | 3.6% | — | 76.7% |
| 신규 어휘 사전 단독 | 44.8% | 61.8% | 1.5% |
| **최종 가중치 합** | **42.9%** | — | **2.4%** |

기존 로직은 81개 중 5개 카테고리만 다뤄 76.7%를 무판정으로 넘겼다.

### 측정으로 찾아낸 결함 네 가지

측정을 붙이지 않았으면 전부 놓쳤을 것들이다. 처음 구현의 가중치 합은 21.9%였다.

| 결함 | 증상 | 수정 |
|---|---|---|
| 사전의 2·3위를 경쟁 후보로 등록 | 사전이 고른 답의 차점자가 라이벌이 되어 마진 검사를 스스로 못 넘김. 무판정 55% | 1위만 기여하고, 2위를 앞선 정도를 가중치에 반영 |
| 5대 장르가 사전을 뒤집음 | 5개 카테고리만 아는 분류기가 81개를 아는 분류기와 동등한 표를 행사. 사전의 정답을 63건 뒤집음 | 상한을 사전 하한보다 1.25배 아래로 |
| 가중치 사다리 간격 붕괴 | 확신 높은 사전(2.5)이 dc:subject(2.6)와 1.04배로 붙어 둘 다 무효 | 전 구간 1.26배 이상으로 재배치 |
| 빌드와 판정의 본문 분량 불일치 | 사전은 30,000자로 만들고 판정은 5,000~10,000자만 봄 | 본문 추출을 `backend/category_lexicon.py` 로 옮겨 같은 함수를 쓰게 함 |

| 단계 | 가중치 합 | 무판정 |
|---|---|---|
| 최초 | 21.9% | 55.0% |
| 사전 1위만 기여 | 30.5% | 20.3% |
| 사다리 재설계 | 35.0% | 5.9% |
| 표본 단어 수 상향 | 36.2% | 5.8% |
| 공통 추출기 사용 | **42.9%** | **2.4%** |

### 남은 오차의 성격

혼동의 대부분은 모델 결함이 아니라 분류 체계에서 온다.

- `4_인문일반논픽션` 이 `4_철학윤리`·`4_역사인물`·`4_사회인류` 를 내용상 포함한다
- `2_을유세계문학전집`, `2_동서문화사월드북`, `4_살림지식총서`, `3_SF그리폰북스` 는
  장르가 아니라 출판사 시리즈다. 본문 어휘로는 원리적으로 구분할 수 없다
- `4_경영마케팅` 과 `6_처세술리더십창의성`, `8_요리음료` 와 `8_건강일반` 은 실제로 겹친다

이 구분은 파일명과 서점 메타데이터가 담당한다. 가중치 합이 두 신호를 함께 쓰는 이유다.
이 측정은 서점 조회를 끈 상태라 운영 조건에서의 하한이다.

단위 테스트는 `tests/test_corpus_lexicon.py`와 `tests/test_category_lexicon.py`에 둔다.
합성 코퍼스를 `tmp_path`에 만들어 `/mnt/data` 의존 없이 돌린다.

## 10. 가정과 남은 위험

- `0_*` 디렉토리를 카테고리에서 제외한다. `0_telegram` 15,876건은 미분류 입력으로 본다.
- 사전 gzip 약 1.5MB를 git에 커밋한다. 생성물이지만 백엔드 런타임이 필요로 한다.
- 백엔드 이미지가 약 135MB 커진다 (kiwipiepy-model 105MB + numpy 30MB).
- 파일이 0건인 7개 카테고리(`1_문헌서지`, `1_올재`, `1_한국고전국역총서`, `3_판타지pdf`,
  `4_누워서읽는법학`, `5_그림으로_읽는`, `8_공인중개사`)는 사전이 없다. 기존 로직에만 의존한다.
- `9_격언명언`(7건), `7_언어일반`(8건), `5_서브컬쳐`(10건), `5_이지사이언스`(18건),
  `3_SF직지`(7건)는 사전을 갖지만 문서 수가 적어 통계 신뢰도가 낮다.
  사전에 `doc_count`를 기록해 `inspect` 로 확인할 수 있게 한다.
- 코퍼스 디렉토리의 기존 분류 자체에 오류가 있으면 사전이 그 오류를 학습한다.
  홀드아웃 정확도가 낮으면 이 가능성을 먼저 의심한다.
